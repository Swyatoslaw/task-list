# Список задач

Статический сайт со списками задач: HTML, CSS и JavaScript без сборки, данные хранятся в [Supabase](https://supabase.com), хостинг — GitHub Pages.

## Возможности

- **Комнаты** (`index.html`) — создание комнаты по названию; список комнат, открытых на этом устройстве.
- **Комната** (`room.html?id=…`) — карточки со списками:
  - создать, переименовать, удалить карточку (с подтверждением);
  - добавить, отредактировать (кнопка или двойной клик), удалить пункт (с подтверждением);
  - завершить пункт — фиксируется дата завершения; снова сделать активным — дата сбрасывается;
  - «основная» карточка (★) показывается первой. Выбор хранится в `localStorage` и действует только на этом устройстве.
- Изменения сразу видны на других устройствах, открывших комнату (Supabase Realtime).
- Адаптивная вёрстка для смартфона и десктопа, светлая и тёмная тема (по умолчанию — как в системе).

## Настройка Supabase

1. Создайте проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor**, вставьте содержимое [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**.
3. В **Project Settings → API** скопируйте *Project URL* и *anon / publishable key* в [`js/config.js`](js/config.js):

   ```js
   export const SUPABASE_URL = 'https://xxxx.supabase.co';
   export const SUPABASE_ANON_KEY = 'eyJ...';
   ```

   Anon key публичный — его можно коммитить. Не используйте `service_role` key.

> Авторизации нет: любой, у кого есть ссылка на комнату, может её читать и изменять. Идентификатор комнаты — случайный UUID, угадать его практически невозможно, но не храните в комнатах секреты.

## Локальный запуск

Нужен любой статический сервер (модули ES не работают через `file://`):

```bash
python -m http.server 8080
```

Затем откройте <http://localhost:8080>.

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<user>.github.io/<repo>/`.

## Структура

```
index.html          страница создания комнат
room.html           страница комнаты
css/style.css       стили, темы, адаптив
js/config.js        ключи Supabase
js/api.js           работа с Supabase
js/storage.js       localStorage: недавние комнаты, основная карточка
js/ui.js            DOM-хелперы, диалоги, уведомления, тема
js/index.js         логика страницы комнат
js/room.js          логика страницы комнаты
supabase/schema.sql схема БД, RLS-политики, realtime
```
